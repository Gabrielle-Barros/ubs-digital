# 01 — Visão Geral do Projeto UBS Digital

## 1. Apresentação

O UBS Digital é uma Prova de Conceito (POC) de um sistema web destinado ao agendamento e gerenciamento de atendimentos em Unidades Básicas de Saúde (UBS).

O projeto surgiu a partir de uma atividade extensionista universitária, com levantamento de informações realizado in loco, buscando identificar oportunidades de melhoria nos processos de atendimento e organização dos serviços de saúde.

## 2. Problema identificado

A organização dos agendamentos e dos horários de atendimento pode envolver processos burocráticos e dificuldades operacionais, impactando tanto os cidadãos quanto os profissionais responsáveis pela gestão da unidade.

## 3. Objetivo

Desenvolver uma solução tecnológica que facilite o acesso da população aos serviços da UBS, otimize a gestão dos horários e contribua para a organização dos atendimentos.

## 4. Proposta de solução

O UBS Digital propõe o desenvolvimento de um sistema web para agendamento e gerenciamento de atendimentos em uma Unidade Básica de Saúde (UBS).

O sistema permitirá que o cidadão consulte os serviços disponíveis, visualize os dias e horários com vagas e realize seu agendamento automaticamente, respeitando a disponibilidade previamente configurada pela equipe da unidade.

A equipe da UBS poderá administrar os serviços, profissionais, horários, quantidade de vagas por turno e agendas destinadas exclusivamente a públicos específicos, como gestantes.

O sistema também contará com funcionalidades administrativas para gerenciamento de ocorrências operacionais que possam comprometer os atendimentos programados, permitindo a comunicação com os cidadãos afetados e a orientação para reagendamento.

A proposta busca reduzir a burocracia, facilitar o acesso aos serviços e melhorar a organização da rotina de atendimento da unidade.

## 5. Tecnologias previstas

- Python e FastAPI — Backend.
- JavaScript e React — Frontend.
- PostgreSQL — Banco de dados.
- Git e GitHub — Versionamento e documentação.

## 6. Escopo inicial

A primeira versão será desenvolvida como uma POC, contemplando uma UBS piloto, com arquitetura planejada para permitir futuras expansões.
